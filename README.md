# My Stack Chrome Theme

<badge color="success">Projeto concluído</badge>

## Como instalar

1. Clone o repositório:
   ```bash
   git clone https://github.com/MoisesAzevedo/my-stack-chrome-theme.git
   ```
2. Acesse as extensões do Chrome: [chrome://extensions](chrome://extensions).
3. Ative o **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação**.
5. Selecione a pasta `my-stack-chrome-theme`.

Pronto! O tema será aplicado automaticamente.

## Personalizar imagem

1. Acesse `my-stack-chrome-theme/images`.
2. Substitua `fundo.png` pela imagem desejada.
3. Mantenha o nome `fundo.png`.
4. Em `chrome://extensions`, clique em **Atualizar** na extensão.
